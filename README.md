# Audit Stock Count

เว็บแอปสำหรับฝ่าย Audit ใช้นำเข้าข้อมูลสินค้า ตรวจจับคู่รายการเคลื่อนไหว นับสต็อกบนโทรศัพท์ เก็บ Audit Trail และส่งออก Excel โดยข้อมูลทั้งหมดเก็บใน IndexedDB ของอุปกรณ์ ไม่ใช้ Firebase

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป จากนั้นรัน:

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal หากต้องการตรวจคุณภาพให้รัน `npm run typecheck`, `npm run lint`, `npm test` และ `npm run build`

## ขั้นตอนทำงาน

1. ไปที่ **ไฟล์ Allowance** แล้วเลือก `.xlsx` หรือ `.xls` ระบบจะหาคอลัมน์รหัสสินค้า ชื่อสินค้า หน่วย หมวด และหมวดสินค้า แสดงจำนวนเพิ่ม/อัปเดต/ข้าม/ซ้ำ/ไม่ครบก่อนบันทึก รหัสซ้ำหรือข้อมูลสำคัญไม่ครบจะไม่ถูกบันทึก และสินค้าเดิมที่ไม่อยู่ในไฟล์ใหม่จะไม่ถูกลบ
2. ไปที่ **ไฟล์รายการเคลื่อนไหว** แล้วเลือกไฟล์ ระบบรองรับหัวรายงานก่อนตารางและค่าเริ่มต้น A=รหัส, C=ชื่อ, D=หน่วย, O=ยอดคงเหลือ พร้อมตรวจหา Header แบบยืดหยุ่น รายการที่ไม่พบใน Allowance จะไม่เข้าสู่รอบนับและส่งออกแยกได้
3. เลือกรายการที่จับคู่ได้แล้วกด **นำรายการที่เลือกไปนับสต็อก** หากยังไม่มีรอบ ระบบจะขอชื่อสาขา วันที่ ผู้ตรวจนับ และหมายเหตุ
4. ในหน้า **นับสต็อก** แตะสินค้า เลือกเพิ่ม/ลบ กรอกจำนวนด้วยแป้นตัวเลข และยืนยัน ทุกการบันทึกสร้าง Transaction ใหม่ ไม่มีการเขียนทับประวัติ
5. กด **Export Excel** เพื่อสร้างไฟล์ 3 Sheet: สรุปการนับ, ประวัติการนับ และรายการไม่พบใน Allowance ตัวเลขเป็นชนิด Number และวันที่เป็นชนิด Date ของ Excel

## Demo Data

ปุ่ม **เปิด Demo** ในหน้า Allowance เพิ่มสินค้าตัวอย่างและประวัติตัวอย่างที่แยกด้วยหมวด `__DEMO__` ปุ่ม **ปิด Demo** ลบเฉพาะข้อมูลตัวอย่าง ไม่กระทบข้อมูลจริง

## หมายเหตุการใช้งาน

- ข้อมูลอยู่ใน Browser/อุปกรณ์ที่ใช้งาน ควร Export Excel ก่อนล้างข้อมูล Browser หรือย้ายเครื่อง
- PWA สามารถติดตั้งจากเมนู Browser และใช้งานหลังโหลดแอปครั้งแรก
- รหัสสินค้าเก็บเป็นข้อความเสมอ เพื่อรักษาเลขศูนย์ด้านหน้าและลดความเสียหายจาก Scientific notation
- ชั้น `services/auditRepository.ts` แยกการเข้าถึงข้อมูลออกจาก UI เพื่อเปลี่ยนไปใช้ API บริษัทภายหลังได้
